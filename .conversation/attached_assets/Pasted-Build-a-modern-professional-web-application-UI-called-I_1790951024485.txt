Build a modern, professional web application UI called **InsightForge**.

### Project

**InsightForge — AI-Powered Data Science & Decision Intelligence Platform**

InsightForge is a data science platform where users can upload datasets and perform automated data profiling, exploratory data analysis, statistical analysis, machine learning, model comparison, explainable AI, experiment tracking, and AI-powered natural-language data analysis.

For this first version, focus **ONLY on the frontend UI and user experience**. Do not implement the actual machine learning, statistical analysis, database, or AI-agent functionality yet. Use realistic mock/sample data wherever necessary so the interface looks functional and polished.

### Target Users

Data Science students, analysts, ML engineers, researchers, and developers.

### Design Direction

Create a premium, modern **AI + Data Science SaaS dashboard**.

The design should feel:

* Professional
* Technical
* Clean
* Modern
* Data-focused
* Minimal but visually impressive
* Suitable for a portfolio project and real product

Avoid making it look like a generic CRM or basic admin panel.

Use:

* Dark modern dashboard theme
* Subtle gradients
* Glass/soft card effects where appropriate
* Clean typography
* Smooth micro-animations
* Interactive hover states
* Professional charts
* Clear spacing and hierarchy
* Responsive design for desktop, tablet, and mobile

Do not overuse gradients, glowing effects, or animations. Keep the interface professional.

### Main Navigation

Create a left sidebar with:

1. Overview
2. Datasets
3. Data Profiling
4. Exploratory Analysis
5. Statistics
6. ML Lab
7. Model Explainability
8. Experiments
9. AI Data Analyst
10. Reports

At the bottom of the sidebar include:

* Settings
* Help
* User profile

The sidebar should be collapsible.

### Important UI Requirements

Use reusable components.

Create:

* Sidebar
* Header
* Cards
* Charts
* Tables
* Dataset cards
* Metric cards
* Modal dialogs
* Upload component
* Empty states
* Loading states
* Error states
* Toast notifications

Use realistic sample data instead of lorem ipsum.

Make all navigation functional on the frontend.

Add smooth page transitions and subtle animations.

Ensure the UI is fully responsive.

### Technical Requirements

Use a modern React-based frontend.

Prefer:

* React
* TypeScript
* Tailwind CSS
* Recharts or another suitable charting library
* Lucide icons

Keep the architecture modular so that the frontend can later connect to:

**React Frontend → FastAPI → Python Data Science/ML Engine → Database**

Do not implement the backend yet.

Do not hardcode the UI in one huge component.

Create reusable components and a clean folder structure.

### Most Important Requirement

The application should look like a **real professional Data Science product**, not a student CRUD dashboard.

The core visual identity should communicate:

**Data → Analysis → Machine Learning → Explainability → AI Insights → Decision**

Build the UI with that product philosophy in mind.
