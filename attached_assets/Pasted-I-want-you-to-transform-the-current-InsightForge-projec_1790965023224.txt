# 12. Automated ML Workflow

When the user selects a target column, InsightForge should:

1. Determine whether the task is likely classification or regression.
2. Separate features and target.
3. Detect numerical and categorical features.
4. Handle missing values.
5. Encode categorical features.
6. Scale features when appropriate.
7. Split data into train/test sets.
8. Train selected models.
9. Evaluate them.
10. Compare results.
11. Store experiment information.

The user should also be able to manually configure the workflow.

Do not automatically select a "best model" using arbitrary assumptions. Present the measured evaluation metrics and let the user inspect the results.
